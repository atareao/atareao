## 🦀 Lo que estoy construyendo ahora

Una **suite de auto-hospedaje escrita en Rust**: WAF, despliegue con Podman, monitorización, backups y gestión de secretos. Rootless, declarativa y sin depender de nadie.

| Proyecto | Qué hace |
| --- | --- |
| **[shuul](https://github.com/atareao/shuul)** | WAF ForwardAuth y rate limiting estilo fail2ban para Traefik, con panel de administración en React |
| **[self-hosted-podman](https://github.com/atareao/self-hosted-podman)** | Despliegue de servicios auto-hospedados sobre Podman rootless con Traefik, quadlets y secretos con SOPS |
| **[qctl](https://github.com/atareao/qctl)** | CLI para gestionar quadlets de Podman |
| **[alloy](https://github.com/atareao/alloy)** | Dashboard de gestión de Docker en tiempo real, con backend en Rust y frontend en React |
| **[kesto](https://github.com/atareao/kesto)** | Orquestador de backups: volcados de MariaDB/PostgreSQL y directorios hacia repositorios rustic en S3 |
| **[watchbeat](https://github.com/atareao/watchbeat)** | Monitor de uptime auto-hospedado con alertas multicanal, páginas de estado y OIDC |
| **[crypta](https://github.com/atareao/crypta)** | Gestor de secretos compatible con SOPS/Age, con sincronización automática vía Git |
| **[u2vpodcast](https://github.com/atareao/u2vpodcast)** | Convierte tus canales de YouTube favoritos en feeds de podcast RSS |
